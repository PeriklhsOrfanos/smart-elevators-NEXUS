## 6. Known Limitations

Η συγκεκριμένη έκδοση υποστηρίζει βασική προσομοίωση μετακίνησης. Η αλλαγή ορόφου πραγματοποιείται άμεσα και δεν έχει υλοποιηθεί ακόμη προσομοίωση χρόνου μετακίνησης, διαχείριση θυρών ή ουρά στάσεων.

Επίσης, ο Elevator Controller δεν έχει συνδεθεί ακόμη με τον Central Controller μέσω REST.

## 8. Prompts and AI Responses

Στην ενότητα αυτή καταγράφονται αυτούσιες οι προτροπές που χρησιμοποιήθηκαν για την υλοποίηση του Elevator Controller και οι αντίστοιχες απαντήσεις του ChatGPT.

### Interaction 1 — Elevator Controller implementation

**User Prompt:**

ωραια παμε να συνεχισουμε με την υλοποιηση του elevatorController
**AI Response:**

Το ChatGPT πρότεινε την υλοποίηση του υποσυστήματος Elevator Controller, αξιοποιώντας ως αφετηρία τον υπάρχοντα κώδικα της ομάδας και προσαρμόζοντάς τον στη δομή Maven του NEXUS.

Παρείχε τον κώδικα της κλάσης `ElevatorController.java`, η οποία περιλαμβάνει:

- Αναγνωριστικό ανελκυστήρα από A έως T.
- Αρχικό όροφο και συνολικό αριθμό ορόφων.
- Έλεγχο εγκυρότητας των παραμέτρων.
- Ανεξάρτητο HTTP server.
- REST endpoint `GET /api/elevator/status` για επιστροφή της κατάστασης του ανελκυστήρα.
- REST endpoint `POST /api/elevator/move` για μετακίνηση σε συγκεκριμένο όροφο.
- Διαχείριση καταστάσεων `IDLE`, `MOVING_UP` και `MOVING_DOWN`.

Επίσης, πρότεινε διαφορετική θύρα επικοινωνίας για κάθε ανελκυστήρα, ώστε να αποφεύγονται συγκρούσεις με τον Central Controller που χρησιμοποιεί τη θύρα 8080.

Για την πρώτη δοκιμή δόθηκαν οι ακόλουθες εντολές:

```bash
mvn clean test

java -cp target/classes gr.aueb.dmst.elevators.elevator.ElevatorController A 1 10 8081

curl -i http://localhost:8081/api/elevator/status

curl -i -X POST http://localhost:8081/api/elevator/move -d '7'

curl -i http://localhost:8081/api/elevator/status
```

Το AI διευκρίνισε ότι η πρώτη υλοποίηση πραγματοποιεί στιγμιαία μετακίνηση και δεν υποστηρίζει ακόμη χρόνο κίνησης, ουρά στάσεων ή προσομοίωση θυρών.

### Interaction 2 — Code improvements

παμε τωρα να τελειοποιησουμε τον κωδικα και να κανουμε βελτιωσεισ οπου χρειαζεται

**AI Response:**

Το ChatGPT εξέτασε την κατάσταση του NEXUS και τα αποτελέσματα των δοκιμών του Elevator Controller.

Αναγνώρισε ότι ο Elevator Controller λειτουργεί ως ανεξάρτητο υποσύστημα, αλλά δεν επικοινωνεί ακόμη με τον Central Controller.

3. Προσθήκη JUnit tests για τον Elevator Controller.

6. Ενοποίηση της διαμόρφωσης των ορόφων μεταξύ των υποσυστημάτων.
7. Προετοιμασία μετρικών, UML και τεκμηρίωσης για τη δεύτερη παρουσίαση.

Επίσης, πρότεινε χειροκίνητες δοκιμές του REST API για την απόρριψη μη έγκυρων προορισμών, μη αριθμητικών εισόδων και λανθασμένων HTTP methods.

Οι εντολές ελέγχου ήταν:

```bash
curl -i -X POST http://localhost:8081/api/elevator/move -d '250'

curl -i -X POST http://localhost:8081/api/elevator/move -d 'abc'

curl -s http://localhost:8081/api/elevator/status
```

Στόχος ήταν να επιβεβαιωθεί ότι λανθασμένα αιτήματα δεν μεταβάλλουν την κατάσταση του ανελκυστήρα.
