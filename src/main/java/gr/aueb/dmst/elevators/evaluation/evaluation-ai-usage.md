# Τεκμηρίωση Χρήσης ΠΤΝ — Evaluation Engine

## 1. Μοντέλα και Εργαλεία
- **Εργαλείο:** Google Gemini (Web)
- **Μοντέλο:** Gemini
- **Κόστος:** Δωρεάν έκδοση (€0 / μήνα — εντός του ορίου των €20).

## 2. Ρόλος ΠΤΝ και Προτροπές (Prompts)
- **Ρόλος ΠΤΝ:** `code-suggestion`, `explanation`, `documentation`
- **Προτροπή 1:** Πρόταση υλοποίησης σε Java για τη δομή της κλάσης `TestScenario` με βάση τις απαιτήσεις που όρισα (αποθήκευση ονόματος σεναρίου, λίστας αιτημάτων και έλεγχος εγκυρότητας ορόφων).
- **Προτροπή 2:** Επιβεβαίωση της σωστής δομής πακέτων Maven, της διαχείρισης του branch στο GitHub και μορφοποίηση της τεκμηρίωσης χρήσης ΠΤΝ.

## 3. Ανάλυση Χρηματικού και Ενεργειακού Κόστους
- **Χρηματικό κόστος:** €0 (χρήση δωρεάν έκδοσης).
- **Ενεργειακό κόστος:** Ελάχιστο (σύντομες, στοχευμένες προτροπές κειμένου).

## 4. Ανθρώπινη Συνεισφορά (Προστιθέμενη Αξία)
- **Αρχιτεκτονική & Σχεδιασμός:** Καθόρισα τη λογική της κλάσης `TestScenario.java`, τα πεδία που απαιτούνται (`scenarioName`, `requests`) και τους κανόνες ελέγχου σφαλμάτων (απόρριψη αρνητικών ορόφων και αιτημάτων με ίδιο όροφο αφετηρίας και προορισμού).
- **Έλεγχος & Προσαρμογή Κώδικα:** Εξέτασα γραμμή προς γραμμή τις προτάσεις του εργαλείου, διασφάλισα την επιστροφή αντιγράφου της λίστας (`new ArrayList<>(requests)`) για προστασία των δεδομένων (encapsulation) και προσάρμοσα τον κώδικα στις προδιαγραφές του project.
- **Διαχείριση Έκδοσης (Git):** Δημιούργησα και διαχειρίστηκα το ξεχωριστό branch (`evaluation-engine`), ενσωμάτωσα τα αρχεία στη σωστή ιεραρχία πακέτων (`gr.aueb.dmst.elevators.evaluation`) και διόρθωσα τυπογραφικά σφάλματα στη διαδρομή πριν την τελική καταχώριση.
